# REG-DIG-USP1079 v2 — Regulatory Digest: USP <1079> Risks and Mitigation Strategies for the Storage and Transportation of Finished Drug Products, and <1079.2> Mean Kinetic Temperature in the Evaluation of Temperature Excursions

**Owner:** Regulatory Affairs · **Status:** Effective · **Effective date:** 2025-10-01

## Key points for excursion assessment
1. MKT is a single calculated temperature that simulates the non-isothermal effects of storage temperature variations. It is a **storage** concept and is applied to transportation excursions only with care.

2. <1079.2> states that MKT should **not** be used to justify **repeated** excursions on the same lane or storage location; repeated excursions indicate a system that is not in a state of control and require investigation and corrective action rather than case-by-case release.

3. MKT should not be used where any single reading exceeds the temperature supported by stability data (the ceiling); the Arrhenius averaging is not valid across a degradation threshold.

4. MKT should not be used for products whose degradation is not Arrhenius-like (for example many biologics and lipid nanoparticle products); for these the stability profile's explicit time-out-of-refrigeration allowance governs.

5. Cumulative excursion time across the product's life should be tracked; each excursion is assessed against the **remaining** budget.
