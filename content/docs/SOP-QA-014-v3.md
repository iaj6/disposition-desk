# SOP-QA-014 v3 — Assessment and Disposition of Temperature Excursions

**Owner:** Quality Assurance · **Status:** Superseded (by v4 on 2026-01-10) · **Effective date:** 2024-04-02

## Summary of this version
Version 3 did not contain the repeat-excursion clause (now 6.3) and permitted MKT to be used as the sole release criterion where TOR was within budget. It was withdrawn after internal audit finding IA-2025-07 identified two lanes released on MKT despite recurring excursions.

This version is retained for traceability only and shall not be used for decisions (SOP-QA-001 §3.3).
